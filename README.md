# MinorProject - CampusFlow College ERP

CampusFlow is a comprehensive College ERP web application designed to streamline academic operations, attendance management, student requests, and administrative workflows.

## Features

- **Multi-Role Access**: Role-based portals for Students, Teachers, and Administrators.
- **Attendance Management**: Real-time marking and tracking for faculty and students.
- **Academic Nexus**: Course management, timetable viewing, and academic updates.
- **Requests & Approvals**: Automated workflow for leaves, permissions, and official requests.
- **CIT / Student Portal**: Centralized dashboard for student performance, notices, and details.

## Tech Stack

- **Frontend**: React 18, Vite, React Router DOM, Lucide React
- **Styling**: Modern Vanilla CSS Design System with dark mode and glassmorphism accents

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/avinash2005bharti/MinorProject.git
   cd MinorProject
   ```

2. **Navigate to the frontend directory:**
   ```bash
   cd frontend
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
